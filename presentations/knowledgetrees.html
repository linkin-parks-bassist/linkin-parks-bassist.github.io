KnowledgetreesThe diagnosis
Why do we keep running in circles?

We store information for humans.

But our new reader is not human
Pause here. This is the core diagnosis. The problem is not merely prompt quality or model intelligence. The environment represents organizational knowledge in a form optimized for human readers.

A filesystem that doubles as an ontology

The question points at the answer.

Paths carry meaning. Leaves contain direct, current answers. The agent retrieves the smallest useful unit, from one implementation fact to an entire specification.

The path is half the query
The structure is not folders for folders' sake. “How do I test the installer?” naturally predicts the route. Exact wording is not required; lexical lookup and semantic branches support discovery.

KnowledgetreesKnowledge lifecycle
No more archaeology by chronology

Current truth has one owner.

When reality changes, rewrite the governing answer. Git keeps history. The active tree tells the next agent what is true now.

$ kt lookup "what is the state"
→ direct current answer
$ evidence contradicts it
→ stop · repair owner · reconcile dependents
$ future agent asks again
→ no repeated rediscovery
Current state is mutable · history is separate
This addresses stale specs and plan changes directly. The answer is maintained in place; chronology belongs in Git or explicit history, not mixed into operational truth.

KnowledgetreesTrust without magic
Knowledge can still be incomplete or stale

Reconnect claims to reality.

Green

No detected failure

Usable after checking scope and evidence. Green is not a blanket claim of truth.

Yellow

Needs re-verification

Freshness expired. Review the whole answer before renewing it.

Brown

Stop and repair

A proof failed, structure broke or the claim was falsified.

Executable proofs where facts are mechanically checkable
Avoid overselling. Knowledgetrees do not eliminate source reading, testing or judgment. They make knowledge owned, auditable and able to carry explicit evidence and bounded proofs.
