Read left to right. Each logical voice has independent phase, LFO, envelope, filter, velocity, and replacement state. HLS unroll factor four creates four physical process_voice lanes, each serving four logical voices sequentially. Their partial sums converge through the timing-friendly two-level tree before the shared reverb and output path.

Embedded softwareWhy EDF + ALSA
Use the processing system as an architectural strength

Manage devices in Linux. Keep PL deterministic.

EDF / PS-managed architectureDirect MIDI decoding in PL
ALSA Sequencer provides standard MIDI events and mature device handling.Requires custom USB/transport and parser integration.
Discovery, disconnect, and reconnect are ordinary Linux service concerns.Device lifecycle becomes hardware behavior.
Voice policy and control mapping change without rebuilding PL.Policy changes require hardware iteration.
EDF + dfx-mgr package and manage a replaceable runtime PL payload.A static payload couples more behavior to the hardware image.
No product requirement justified putting low-rate MIDI policy in PL
This is a product-specific decision, not a claim that PL MIDI decoding is always wrong. EDF provides AMD's curated Yocto flow; ALSA provides mature infrastructure; PL remains focused on deterministic audio.
