05 / FPGA audio

Lyrebird

A sixteen-voice polyphonic synthesizer on an AMD Kria KV260. A USB MIDI controller is read on the Linux side and written into registers in the programmable logic, where an HLS DSP core generates 24-bit, 48 kHz audio: phase-modulation voices with wavefolding, filters, envelopes and LFOs, and a shared reverb, played out over I2S.

MIDI → Linux → PL registers → HLS → I2SActive · Vitis HLS · SystemVerilog · KV260

About.

Background

I came to engineering from pure mathematics, including postgraduate work in category theory. I eventually moved from diagrams and abstractions into digital hardware, embedded systems and FPGA design. That path still shapes how I work: I care about structure, but I want the abstraction to cash out in a system that actually runs.

Right now

I work professionally with embedded compute and programmable logic, and outside work I build FPGA audio systems, hardware tooling and local-agent infrastructure. I also run a Sydney FPGA/ASIC meetup and help create low-friction ways for people to get hands-on with hardware.
