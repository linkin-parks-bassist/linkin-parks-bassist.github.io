Field note · 21 September 2026 · Jev, on the bench

A counterexample turned Jev's Maybe into No.

I put the same question to Jev alongside 500 different polynomial maps, one call each. Shown a counterexample to the Jacobian conjecture, it said No. Shown a reversible decoy, it said Maybe. Asked with no map at all, it said Maybe.

Instrument
jev, a small local wrapper around one TypeSafe Jev call
Question
“Is the Jacobian conjecture true”, held fixed for every call
Specimens
500 polynomial maps in three variables: 250 counterexamples, 250 bijections
Protocol
One call per map, shuffled with seed
Result
— of answers followed the intended No / Maybe pattern
§ 1 · What I asked

One question, with a formula beside it.

jev is a small command-line wrapper around one TypeSafe Jev Noul API call. It sends the quoted question and the optional where text as separate fields of the request state. Here the where text is only a polynomial. It is never a label saying what kind of map it is.

Jev returns a probability p for Yes. The wrapper prints No when p < 1/3, Maybe when 1/3 ≤ p < 2/3, and Yes otherwise. So “Maybe” is my middle probability band, not a separate word Jev generates. jev --show-probability shows the underlying value.

$ jev 'Is the Jacobian conjecture true' where 'F(x,y,z)=...'
§ 2 · First, no map

Ask the bare question. Then add one formula.

In an earlier exploratory run, the bare question got Maybe three times out of three. Then I held that question fixed and supplied one formula at a time.

Obs. 1 / No context

The conjecture alone

Nothing in the prompt points Jev toward a particular example.

jev 'Is the Jacobian conjecture true'
Maybe
3 of 3 exploratory calls
Obs. 2 / Counterexample

Show the published map

The context contains the polynomial, without a label saying it is a counterexample.

jev 'Is the Jacobian conjecture true' where 'F(x,y,z)=((1+xy)^3z+y^2(1+xy)(4+3xy), y+3x(1+xy)^2z+3xy^2(4+3xy), 2x-3x^2y-x^3z)'
No
3 of 3 exploratory calls; also No in the 500-map run
Obs. 3 / Decoy bijection

Show a reversible map

The same shape, but this polynomial has an explicit inverse.

jev 'Is the Jacobian conjecture true' where 'F(x,y,z)=(x+(y+x^2)*(z+(y+x^2)^2)^2, y+x^2, z+(y+x^2)^2)'
Maybe
2 of 3 exploratory calls (the other was No); also Maybe in the 500-map run

That was the surprising part. I never asked “Is this map bijective?” or “Is this a counterexample?” I only put the formula beside the global question. The original three-call observations are saved in results.json. Three calls per case proves little, so the next step was to find out whether the pattern extended beyond those two examples.

§ 3 · Then, 500 maps

Two families, shuffled, one call each.

I generated and algebraically certified 250 related counterexamples and 250 bijections, shuffled them, and asked Jev once per map. The response matched the intended No-for-counterexample / Maybe-for-bijection pattern on 420 of 500 maps (84.0%).

§ 4 · How the answers split

Salmon is No. Yellow is Maybe.

The prompt did not label a map as a counterexample or a bijection, and it did not ask Jev to classify the map. The two map families were certified with exact symbolic algebra before I sent them.

§ 7 · Method

How the specimens were made.

The counterexample side

The base map has determinant −2 and maps three distinct rational points to the same output. Every generated variant composes it with reversible coordinate changes, and the script checks its Jacobian and collision again with SymPy. These are 250 related maps, not 250 independent discoveries.

The original construction has also been formalized in Isabelle, and an exact audit prints the formula and witnesses.

The bijection side

Each map composes three triangular polynomial shears. The script verifies determinant 1 and checks the explicit inverse symbolically. The first bijection (B00) and the first counterexample (C00) are my original proof-of-concept prompts, verbatim.

The question and the where 'F(x,y,z)=...' shape were held fixed. Only the map changed, and no class label was sent. Each map got exactly one Jev call, so these rates describe this run, not how repeatable Jev is on any single map.

§ 8 · Caveats

What this does and doesn't show.

What this tests: whether Jev's answer to the unchanged global question tracks the mathematical character of an unlabeled map supplied only as context. The observed No / Maybe split is striking evidence of context sensitivity. It does not reveal Jev's internal reasoning, and it does not prove Jev verified each formula. The conjecture is false in dimension three, so the literally correct answer to the global question is No for every row. The No-for-counterexample / Maybe-for-bijection score is a response-pattern measure, shown separately from literal accuracy.
